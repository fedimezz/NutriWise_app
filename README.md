## 📝 À propos

NutriWise est une application web complète de gestion nutritionnelle permettant aux utilisateurs de gérer leur alimentation, suivre leurs activités physiques et planifier leurs repas.

### 🎯 Objectifs

- 🥗 **Explorer** une base de données d'aliments avec leurs valeurs nutritionnelles
- 📖 **Découvrir** des recettes saines et équilibrées
- 📅 **Planifier** des programmes alimentaires personnalisés
- 💪 **Suivre** les activités physiques et l'hydratation
- 🎯 **Atteindre** les objectifs de santé

## ✨ Fonctionnalités

### 👤 Côté Utilisateur

| Fonctionnalité | Description |
|----------------|-------------|
| **Plannings nutritionnels** | Consultation, likes, favoris, planification personnalisée |
| **Calendrier interactif** | Visualisation des plannings par date |
| **Suivi quotidien** | Repas, activités, hydratation, score journalier |
| **Aliments** | Recherche, filtrage, détails nutritionnels, éco-score |
| **Recettes** | Consultation, favoris, étapes détaillées |
| **Profil** | Gestion des informations personnelles |

### 👑 Côté Administrateur

| Fonctionnalité | Description |
|----------------|-------------|
| **Dashboard** | Statistiques globales |
| **Utilisateurs** | CRUD complet (+ suppression groupée) |
| **Aliments** | CRUD avec images |
| **Recettes** | CRUD avec images |
| **Plannings** | CRUD avec assignation utilisateur |
